STEP 2 // 一次真实的"零像素差异"

给表格加黑色实线边框

word_edit_style

plan index 2
word_edit_style(selector={table_index:0,type:table}, style_params={border:{color:"#000000",size:0.5,style:single}})
触发的真实 extra_note NOTE: pixel diff detected NO visible change since the last verified render, despite edits being applied. Check carefully whether the intended change is actually present.
✓ PASSEDconfidence 0.95

这不是摆拍的边界案例，是这次真实运行自己撞上的：python-docx 的 add_table() 默认套用 "Table Grid" 样式，插入表格那一步就已经带上了肉眼可见的 黑色细线边框。所以这一步显式加"黑色实线边框"之后，像素 diff 低于 render/page_diff.py:50 那条 8/255 的容差阈值，触发了 agent/loop.py:670-676 的"检测不到可见变化"分支。独立验证器拿到这条提示后， 仍然基于 AFTER 图本身独立判断表格确实带有边框、符合步骤意图——代码没有替它下结论， 只是如实告诉它"没测到像素差异，请自己再确认一遍"。
